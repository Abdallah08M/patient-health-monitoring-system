#  Patient Health Monitoring System

An IoT-based Patient Health Monitoring System built using **ESP32**, **Wokwi Simulation**, and **ThingSpeak**. This project monitors a patient's vital signs, uploads data to the cloud, and triggers alerts when abnormal readings are detected.

---

##  Project Overview

This project is developed as part of the **IOT A & P Mini Project**.

The system continuously monitors:

-  Heart Rate
-  Body Temperature
-  Blood Oxygen (SpO₂)

If any reading goes outside the safe range, the system activates a buzzer and uploads the readings to ThingSpeak for remote monitoring.

---

##  Objectives

- Monitor patient vital signs.
- Simulate an IoT healthcare device.
- Upload sensor readings to the cloud.
- Generate alerts for abnormal readings.
- Display live health data remotely.
